Discover semantic tables and their field definitions.

## List tables

```
GET /api/v1/projects/{project_id}/tables
```

**Auth:** Project member

**Query parameters:**

| Parameter | Description | Default |
|-----------|-------------|---------|
| `branch` | Branch uid | Production branch |
| `page` | Page number | 1 |
| `limit` | Results per page (max 1000) | 20 |
| `q` | Search name or description (case-insensitive) | — |

**Example:**

```bash
curl -H "Authorization: Bearer $API_KEY" \
     "$BASE_URL/api/v1/projects/tpcds/tables?q=web&limit=100"
```

**Response:** `200 OK`

```json
{
  "results": [
    {
      "uid": "web_sales",
      "name": "Web Sales",
      "description": "Web channel sales fact",
      "physical_name": "web_sales",
      "source": null,
      "tags": [],
      "cost": 10,
      "updated_at": "2026-06-01T12:00:00Z"
    }
  ],
  "page": 1,
  "total_pages": 1,
  "total_count": 3,
  "limit": 100
}
```

## Show table

```
GET /api/v1/projects/{project_id}/tables/{id}
```

**Auth:** Project member

**Query parameters:**

| Parameter | Description |
|-----------|-------------|
| `branch` | Branch uid |
| `include_metadata` | When `true`, add a `metadata` key with the warehouse column metadata Strata has cached for the table |

**Example:**

```bash
curl -H "Authorization: Bearer $API_KEY" \
     "$BASE_URL/api/v1/projects/tpcds/tables/web_sales?include_metadata=true"
```

**Response:** `200 OK`

```json
{
  "uid": "web_sales",
  "name": "Web Sales",
  "physical_name": "web_sales",
  "cost": 10,
  "updated_at": "2026-06-01T12:00:00Z",
  "fields": [
    {
      "uid": "web_net_paid",
      "name": "Web Net Paid",
      "semantic_type": "measure",
      "data_type": "decimal",
      "sql": "sum(ws_net_paid)"
    },
    {
      "uid": "web_sales_sk",
      "name": "Web Sales Key",
      "semantic_type": "dimension",
      "data_type": "integer",
      "sql": "ws_item_sk",
      "primary_key": true
    }
  ]
}
```

`fields` lists every field defined on this table with its SQL expression for this table. The expression flags `primary_key`, `array`, and `lookup` appear only when true. Because a field can be defined on several tables (one name, one concept), the same field uid can appear under more than one table with a different `sql` on each. `id` accepts the table uid or numeric id.
