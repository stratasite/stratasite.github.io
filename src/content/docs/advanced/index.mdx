In-depth and optional semantic-model features. The pages above this section cover the core: tables, fields, expressions, relationships, imports, extended blending groups, and partitions.

## Features

- **[Universe Formation](/docs/advanced/universe-formation/)** - How join trees are built from a root fact
- **[Semantic Routing](/docs/advanced/semantic-routing/)** - How the planner picks a table and datasource
- **[Cost Optimization](/docs/advanced/cost-optimization/)** - Steering routing with cost
- **[Exclusions](/docs/advanced/exclusions/)** - Measures that ignore chosen dimensions
- **[Inclusions](/docs/advanced/inclusions/)** - Multi-level calculations
- **[Decorators](/docs/advanced/decorators/temporal/)** - Transformations (temporal, window, contribution)

## When to Use

Use advanced features when you need:
- **Point-in-time analysis** - [Snapshot measures](/docs/semantic-model/fields/measures/snapshot/)
- **Complex filtering** - Exclusions
- **Multi-level calculations** - Inclusions
- **Hot tiers and aggregate tables** - Semantic routing and cost optimization
- **Time-based analysis** - Temporal decorators
